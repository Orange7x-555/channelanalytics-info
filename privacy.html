ChannelAnalytics

プライバシーポリシー

ChannelAnalytics（以下「このツール」）が Google アカウントを通じて取得するデータの扱いについて説明します。

1. 取得するデータ

このツールは、運営者本人の YouTube チャンネルについて、次のデータを読み取り専用で取得します。

  • チャンネルの基本情報（チャンネル名、登録者数など）
  • 動画の一覧と情報（タイトル、公開日、公開状態、サムネイル、再生数など）
  • YouTube アナリティクスの数字（再生数、視聴時間、視聴維持率など）

使う権限は youtube.readonly と yt-analytics.readonly の 2 つだけです。YouTube 上の内容を書き換えることはありません。

2. 使いみち

取得したデータは、運営者本人が自分のチャンネルの成績を振り返り、動画づくりに役立てるためだけに使います。広告、販売、その他の目的には使いません。

3. 保存する場所

取得したデータは、次の場所にだけ置きます。

  • 運営者本人のパソコンの中
  • 運営者本人の claude.ai アカウント内の、非公開のページ（本人だけが見る成績表）

サインイン用の情報（アクセストークン）も、運営者本人のパソコンの中にだけ保存します。

4. 第三者への提供

取得したデータを第三者に渡したり、売ったり、公開したりすることはありません。

5. アクセスの取り消し

このツールに許可したアクセスは、Google アカウントの設定からいつでも取り消せます。

Google アカウント → サードパーティ製のアプリとサービス

取り消したあとは、このツールは新しいデータを取得できなくなります。パソコンに残ったデータは、運営者本人がいつでも削除できます。

6. Google と YouTube の規約

このツールは YouTube API サービスを使っています。利用にあたっては、次の規約とポリシーが適用されます。

  • YouTube 利用規約
  • Google プライバシーポリシー

Google API から受け取ったデータの使用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

7. 改定

このポリシーを変えるときは、このページを更新します。
